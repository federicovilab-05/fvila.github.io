Política de privacidad de Finanzas bot Finanzas bot es una herramienta de uso personal de Federico Vila. No está disponible para el público. La aplicación accede únicamente a una planilla de Google Sheets y a una carpeta de Google Drive creadas por ella misma en la cuenta de su dueño, para registrar gastos y guardar comprobantes de pago. No se comparten datos con terceros, salvo las imágenes de comprobantes que se envían a la API de Anthropic para leer su contenido. No se venden datos ni se usan con fines publicitarios.
